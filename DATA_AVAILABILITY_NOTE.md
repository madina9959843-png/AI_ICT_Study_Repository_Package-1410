# Data Availability Note

No participant-level empirical dataset is included in this repository.

The authors did not deposit the previously available demonstration workbook because that workbook explicitly identified its questionnaire responses, rubric scores, follow-up values, feedback values, and study-condition allocation as synthetic demonstration data.

The original participant-level research records are not available in a form that can now be independently verified and released as a de-identified public analytical dataset. The authors therefore did not reconstruct individual records from aggregate statistics.

This repository provides the analysis code, data schema, codebook, aggregate effect-size verification inputs, and supplementary methodological materials. Consequently, full participant-level computational reproduction is not possible from the repository alone.
